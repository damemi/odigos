<Info>
  Odigos Enterprise instruments Node.js applications with [eBPF-based instrumentation](/enterprise/instrumentations/nodejs/ebpf) by default.
  To use the native OpenTelemetry Node.js SDK instead, set the container's **Otel Distro Name** to `nodejs-community` in the source drawer, or set `otelDistroName: nodejs-community` under `containerOverrides` in the [Source object](/enterprise/pipeline/sources/introduction).
</Info>
