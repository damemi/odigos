## odigos pro

Manage your Odigos on-prem token and advanced features

### Synopsis

The pro command manages your Odigos on-prem token and provides advanced operations, such as updating Go offsets and managing Odigos Central.

```
odigos pro [flags]
```

### Examples

```

# Renew the on-premises token for Odigos,
odigos pro --onprem-token <token>



```

### Options

```
  -h, --help                  help for pro
      --onprem-token string   On-prem token for Odigos
```
