Findings

The same unified feed the product UI renders (GET /api/v1/findings): policy violations (a guardrail you declared was broken) and anomalies (deviations from learned baselines) as one list, worst first. Each row's summary line comes straight from the API so you can read what happened without opening investigate. The tabs bucket that one feed by what you've acted on.
