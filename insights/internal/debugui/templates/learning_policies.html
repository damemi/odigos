Learning policies

How each deviation class decides it has learned enough to stop learning and start scoring. A policy is a list of conditions combined by a mode (any, all, k of); conditions are count-, time-, or stability-based. Each class has a global default plus optional overrides for a single service or one specific transaction - the most specific policy wins (transaction → service → global). Saved edits apply live, no restart.
