# Odiglet Enterprise

## Setup

Enterprise odiglet uses private repos from github: 
- `"github.com/odigos-io/enterprise-go-instrumentation"`
- `"github.com/odigos-io/ebpf-java-instrumentation"`

To make it work locally, use the following commands:

```sh
export GOPRIVATE=github.com/odigos-io/enterprise-go-instrumentation,github.com/odigos-io/ebpf-java-instrumentation
```
